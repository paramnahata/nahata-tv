# Contributing

Please discuss larger changes in an issue before implementation. Keep D-pad navigation usable, respect disabled animations and avoid adding network access without a documented user need. Check Android 9 compatibility and preserve safe access to system settings and the original launcher.

Before a pull request, build the APK, run Android lint and describe exactly which emulator/device scenarios you checked. Never describe untested firmware behaviour as verified. Screenshots must redact accounts, local addresses and personal content.
