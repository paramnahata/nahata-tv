# Security

The launcher has no Internet permission or analytics. Its optional Home override is limited to stock Google TV launcher window-state events and cannot read window content. Read [PRIVACY.md](PRIVACY.md).

The optional remote bridge is intended only for trusted local Wi-Fi, uses HTTP and requires pairing/session authentication. Do not publish pairing codes, tokens, ADB addresses or logs containing typed text. Do not port-forward ADB or the bridge.

For a suspected vulnerability, use the repository's private vulnerability-reporting channel if available. Otherwise use the contact link on [paramnahata.com](https://paramnahata.com) and do not post credentials or an exploit exposing another user's device in a public issue.

Preview APKs are development-signed and not a statement of production security review. Always compare published checksums and retain a recovery path to the original launcher.
