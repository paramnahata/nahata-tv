# Changelog

## 0.5.1

- Configurable Jio passthrough input for other TV firmware; Hisense hardware-ID fallback is restricted to the known development device.
- Remember the original default Home component when available, rather than assuming every TV uses the same launcher.
- Phone remote menu distinguishes the official laptop-free Google TV path from the optional laptop browser bridge.
- Public installation/update/rollback guide, compatibility matrix, remote architecture note and real-device screenshot gallery.
- Development APK, matching source package, optional laptop bridge and checksums published as a preview release.

## 0.5.0

- Separate original day and moonlit night wallpapers automatically follow Light/Dark appearance, plus Sunset and Aurora background choices.
- Three clear Wi-Fi arcs and a filled signal dot.
- Removed the large changing app title above the dock; added a discreet bottom-right developer credit.
- Long-press Rearrange: Left/Right swaps Home apps, OK saves the order locally, Back cancels the draft. All apps retain their installation state.
- Subtle ambient wallpaper pan/zoom and moving Aurora light, paused when Home loses focus or the app pauses. System reduced-motion and an Ambient motion toggle are respected.

## 0.4.0

- One centred lower glass dock with a sliding focus highlight and soft app-title transitions.
- Midnight Dark and Pearl Light appearance, including custom themed dialogs.
- Original bundled Alpine scenery or Aurora gradient background.
- Compact top controls and removal of Home helper copy and separate large app tiles.

## 0.3.0

- Home defaults to Netflix, Prime Video, YouTube and Live TV; all other apps live in a separate Apps collection.
- Long-press Show on Home / Hide on Home preserves every app in Apps.
- Compact drawn icon controls for Apps, Wi-Fi, Inputs, Remote, Personalise, Settings and About.
- Root Back stays on Nahata Home; single-task Home intents reset the Apps view.
- Optional restricted Home override for firmware that forces the stock launcher; no screen-content access.
- Original launcher can be opened from Personalise without disabling it.
- Local paired phone browser remote with D-pad, swipe focus, volume, app shortcuts and English typing via a laptop bridge.

## 0.2.0

- Glass-style cards, aurora gradient, horizontal app sliders and verified Hisense HDMI 2 shortcut.

## 0.1.0

- First original launcher development preview.
